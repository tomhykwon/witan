# The Strategy Witan

Website for the Strategy Witan, an annual invitation-only conference for the UK strategy community.

Live at https://witan.tomkwon.com

- 2027 host: UCL School of Management (Tom Kwon, Anil Doshi)
- 2028 host: Bayes Business School

Built with a small Python script. Edit `_src/*.html`, run `python3 build.py`, commit. See `CLAUDE.md` for details.
